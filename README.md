# AguaPremium3
# 💧 Reparto de Agua - Tucumán

Una landing page diseñada para un servicio local de distribución de agua en San Miguel de Tucumán y zonas aledañas. El sitio está enfocado en transmitir una imagen visual de pureza, hidratación y frescura, ideal para captar la atención de clientes residenciales y comerciales.

## 🚀 Características Principales

* **Catálogo y Precios:** Sección detallada con los valores actualizados de los diferentes formatos de agua (bidones, botellas, dispensers, etc.).
* **Ubicación de la Planta:** Información clara y directa sobre la dirección física de la planta purificadora y de envasado.
* **Diseño Temático (Frescura):** Interfaz de usuario limpia, utilizando paletas de colores acuáticos, tipografías legibles y elementos visuales que refuerzan la idea de agua pura y cristalina.
* **Responsive Design:** Adaptable a dispositivos móviles, tablets y pantallas de escritorio.

## 🛠️ Tecnologías Utilizadas

* HTML5
* CSS3
* JavaScript
* Bootstrap

## 💻 Instrucciones para Visual Studio Code

Para visualizar, editar o continuar trabajando en este proyecto en tu entorno local:

1. Abre **Visual Studio Code**.
2. Abre la carpeta raíz del proyecto (`Archivo > Abrir carpeta...`).
3. Te sugiero utilizar la extensión **Live Server**. Si la tienes instalada, simplemente haz clic derecho sobre el archivo `index.html` y selecciona **"Open with Live Server"**. 
4. La página se abrirá en tu navegador predeterminado y cualquier cambio que guardes en el código se reflejará automáticamente.
